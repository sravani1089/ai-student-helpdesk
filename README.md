# AI Student Helpdesk & Issue Tracker

A beginner-friendly web application that helps students submit, track, and manage college-related issues.

## Project Overview

The AI Student Helpdesk & Issue Tracker allows students to report problems related to college portals, fees, internet connectivity, examinations, and other academic services.

The application categorizes submitted issues using JavaScript keyword-based rules and displays relevant troubleshooting suggestions.

## Features

- Submit student issues through a form.
- Generate a unique tracking ID for each issue.
- Automatically categorize issues based on keywords.
- Display relevant suggestions for each category.
- Track issue status: Open, In Progress, and Resolved.
- Search issues by title or tracking ID.
- Edit and delete submitted issues.
- View a dashboard showing issue counts by status.
- Save issue data in browser local storage.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Submit an issue and explore the available features.

## Current Implementation

This version uses rule-based JavaScript keyword matching to categorize issues and provide suggestions. It does not yet use an external AI API or a backend database.

Issue information is stored locally in the browser.
